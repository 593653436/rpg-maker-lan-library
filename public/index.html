CURATE THE SHELF

添加一个游戏

支持本地磁盘与 SMB/UNC 任意地址：RPG Maker 网页目录（index.html / www/index.html）与 KRKR/Kirikiri 2 游戏目录（data.xp3）。游戏资源保持在原位置，只读按需加载，不复制原游戏。
启动器 / 语言版本
网页模式不会直接运行 EXE；支持的语言启动器会作为只读覆盖层加载，NAS 原文件不会修改。

SELECT ARTWORK

更改封面

已自动查找标题图、封面、图标和图片目录；RPG Maker 加密图片会在读取时即时解密，不写入本机磁盘。

SELECT LAUNCHER

选择启动器

选择网页模式使用的语言版本。首次切换封装启动器时需要准备本地只读覆盖层。

SELECT TRANSLATION

选择翻译文件

只列出游戏根目录中能解析为翻译映射的 JSON/JSONY；选择结果会保留，刷新不会重新覆盖。
